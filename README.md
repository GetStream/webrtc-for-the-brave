# WebRTC for the Brave 😎

## WebRTC Basics & Making Your First Call

This repository contains interactive tutorials for the **WebRTC Basics** module from the comprehensive [WebRTC for the Brave tutorial series](https://getstream.io/resources/projects/webrtc). This module guides you through building a peer-to-peer video call application using WebRTC. You'll master essential WebRTC APIs while implementing a Node.js-based signaling server to establish connections between browsers.

## What You'll Learn

Through hands-on code samples and practical examples, this module covers:

- **Media Stream API**: Learn how to capture and display video/audio streams from local devices
- **RTCPeerConnection**: Understand how to establish peer-to-peer connections between browsers
- **RTCDataChannel**: Implement real-time data transmission between peers
- **Screen Sharing**: Add screen sharing capabilities to your WebRTC applications
- **Signaling Servers**: Build the infrastructure needed to coordinate WebRTC connections

## Interactive Lessons

### Lesson 1: Media Stream API
**[Get a Media Stream](https://getstream.github.io/webrtc-for-the-brave/lesson01-1/index.html)**

Learn how to use the WebRTC Media Stream API to capture video from your webcam and display it in the browser. This lesson covers `getUserMedia()`, media constraints, and handling user permissions.

*Based on: [Using WebRTC Media Stream API](https://getstream.io/resources/projects/webrtc/basics/mediastream/)*

### Lesson 2: RTCPeerConnection
**[Peer Connection](https://getstream.github.io/webrtc-for-the-brave/lesson01-2/index.html)**

Discover how to create peer-to-peer connections using RTCPeerConnection. Learn about SDP (Session Description Protocol) messages, ICE candidates, and the WebRTC connection establishment process.

*Based on: [Creating a Peer Connection](https://getstream.io/resources/projects/webrtc/basics/rtcpeerconnection/)*

### Lesson 3: RTCDataChannel
**[Transmit Text Data](https://getstream.github.io/webrtc-for-the-brave/lesson01-3/index.html)**

Explore real-time data transmission using RTCDataChannel. Build applications that can send text messages, files, or any binary data directly between browsers without going through a server.

*Based on: [RTCDataChannel Tutorial](https://getstream.io/resources/projects/webrtc/basics/rtcdatachannel/)*

### Lesson 4: Screen Sharing
**[Screensharing](https://getstream.github.io/webrtc-for-the-brave/lesson01-4/index.html)**

Implement screen sharing functionality using the `getDisplayMedia()` API. Learn how to capture screen content and share it with other peers in real-time.

*Based on: [Screen Sharing Tutorial](https://getstream.io/resources/projects/webrtc/basics/screensharing/)*

### Lesson 5: Signaling Server
**Coming Soon: Signaling Server Implementation**

Learn how to build a Node.js-based signaling server to coordinate WebRTC connections between multiple clients. Understand the role of signaling in WebRTC and implement a complete peer-to-peer communication system.

*Based on: [Building a Simple Signaling Server](https://getstream.io/resources/projects/webrtc/basics/signaling-server/)*

## Getting Started

1. Clone this repository
2. Open any lesson's `index.html` file in your browser
3. Follow the interactive tutorials to learn WebRTC step by step
4. Experiment with the code and build your own WebRTC applications

## Prerequisites

- Basic knowledge of HTML, CSS, and JavaScript
- A modern web browser with WebRTC support
- A webcam and microphone for testing media features
